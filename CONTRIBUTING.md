
# Contributing Guidelines

Thank you for your interest in contributing to Marine Biology App!

## How to Contribute

1. Check existing Issues before starting.
2. Create an Issue to report bugs or suggest features.
3. Create a separate branch for your changes.
4. Keep your changes small and focused.
5. Submit a Pull Request with a clear description.

## Code and Documentation

- Write clear and readable code.
- Use meaningful names.
- Update documentation when necessary.

Thank you for helping improve this project!
